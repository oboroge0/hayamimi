# hayamimi documentation index

日本語版: [README.ja.md](README.ja.md)

Everything under `docs/` is grouped by what you want from it, not by when it
was written. Each entry says what it is, what language it is in, and whether
it is a **conclusion** (kept current) or a **dated record** (a snapshot of a
run, never rewritten afterwards).

**Language policy.** English is primary and Japanese sits alongside it, in
the `README.md` + `README.ja.md` pattern. Files written in Japanese before
that policy stay Japanese and are tagged `ja` below; they are not stale, just
untranslated. New documents should be English, with a `.ja.md` counterpart
where a Japanese reader needs one.
