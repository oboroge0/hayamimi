### 推奨デフォルト閾値

- **babble_snr10**: 単独LIDだけで95%に達する言語のうち最も遅いのは zh（2.5秒）。ja, ko, yue は7秒枠内で単独LIDが95%に到達しないため、これらの言語は長さによらず二重判定（whisper-tiny と SenseVoice 一致）にフォールバックする必要がある。
- **clean**: 単独LIDだけで95%に達する言語のうち最も遅いのは ja（4.0秒）。yue は7秒枠内で単独LIDが95%に到達しないため、これらの言語は長さによらず二重判定（whisper-tiny と SenseVoice 一致）にフォールバックする必要がある。

yue は whisper-tiny の出力語彙にCantoneseクラスが無く、常に zh 系タグに丸められるため（asr_engine.py のコメント参照）、単独LIDでは**原理的に**95%に到達しない。yue の切り替えは常に SenseVoice 内蔵LID（またはその一致確認）に委ねるのが正しい設計であり、計測結果はその前提を裏付けている（全長で0%）。

- **babble_snr10**: 7/7 長さ帯で「一致時正解率」が「単独LID全体正解率」を上回った（例: 2.0秒で単独59% → 一致時85%）。二重判定は特に短尺（0.5〜2.0秒）で単独LIDより明確に信頼できる。

- **clean**: 7/7 長さ帯で「一致時正解率」が「単独LID全体正解率」を上回った（例: 2.0秒で単独61% → 一致時98%）。二重判定は特に短尺（0.5〜2.0秒）で単独LIDより明確に信頼できる。


**推奨ポリシー**: 言語がSenseVoice対応5言語（ja/en/zh/ko/yue）のいずれかである限り、上表の単独LID 95%到達長に達するまでは「whisper-tiny と SenseVoice 内蔵LIDが一致した場合のみ言語切り替えを確定する」二重判定を使い、到達後は単独LIDの結果をそのまま採用してよい。yue（および騒音下のja/ko）は本評価の7秒枠内で単独LIDが95%に届かないため、これらは長さに関わらず二重判定（不一致なら様子見を継続）をデフォルト運用とすることを推奨する。
